# Car Price Prediction using Machine Learning

## Overview

This project predicts the selling price of used cars using machine learning regression models.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models

- Linear Regression
- Random Forest Regressor

## Features

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Label Encoding
- Model Training
- Model Evaluation
- Feature Importance
- Model Saving

## Dataset

CarDekho Used Car Dataset
