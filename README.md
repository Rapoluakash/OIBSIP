# OIBSIP
# Oasis Infobyte Data Science Internship Projects

This repository contains the Data Science internship projects completed as part of the Oasis Infobyte Skill India Program (OIBSIP).

## Projects

### 1. Email Spam Detection
- Built a machine learning model to classify SMS messages as Spam or Ham.
- Technologies: Python, Pandas, Scikit-learn, NLTK.

### 2. Car Price Prediction
- Developed a regression model to predict used car prices.
- Technologies: Python, Pandas, Scikit-learn.

### 3. Sales Prediction
- Built a machine learning model to predict product sales using advertising data.
- Technologies: Python, Pandas, Scikit-learn.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- NLTK
- Jupyter Notebook
